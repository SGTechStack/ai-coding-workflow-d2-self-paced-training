Matt Pocock's Agentic Engineering Workflow

Five phases that take you from idea to a shipped, merge-request-ready feature

01

Architecture

Step 1base
/setup-matt-pocock-skills
Configures your issue tracker, triage labels, and the domain documentation that provides the core rules and vocabulary of your business. Run once per repository.
02

Specification

Step 4base
/wayfinder
Breaks down complex problems into a clear sequence of step-by-step decision tickets, solving each unknown before moving forward.
Step 5base
/to-spec
Synthesises your technical decisions into a clear Technical Requirements Document (TRD) and publishes it.
03

Decomposition

Step 7base
/to-tickets
Converts the TRD into thin, vertical tracer-bullet tickets that cut through every layer of the app, mapping out the exact order they must be completed.
04

Implementation

Step 9base
/implement
Resolves each ticket independently using test-driven development, running a rigorous AI code review before every commit.
05

Closeout

Step 10base
/improve-codebase-architecture
Scans the codebase for technical debt and refactoring opportunities after the feature is built.
Step 12base
/diagnosing-bugs
Provides a step-by-step debugging loop to safely reproduce, isolate, and fix complex issues.
